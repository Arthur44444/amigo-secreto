<h1>🎁 Amigo Secreto</h1>

<h3>Projeto de Amigo Secreto desenvolvido com HTML, CSS e JavaScript, que permite adicionar participantes e realizar o sorteio de forma automática e organizada, garantindo que cada pessoa receba um amigo diferente.</h3>

<br><h2>✨ O que o projeto faz</h2>

<h3>Adiciona nomes de participantes ao sorteio<br>

<br>Exibe a lista de amigos incluídos

<br>Realiza o sorteio automaticamente

<br>Garante que ninguém tire a si mesmo

<br>Mostra claramente o resultado do sorteio

<br>Permite reiniciar o processo quando necessário</h3>
